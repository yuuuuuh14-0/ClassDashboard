# 학교 학급별 진도 대시보드 프로그램

초등학교 선생님이 학급별 과목·단원 진도를 기록하고, 같은 학년의 진도를 함께 확인하는 프로그램입니다.

- [제품 요구사항](PRD.md)
- [설계서](docs/DESIGN.md): 역할별 권한, 화면, 데이터 구조, 진도 계산, 학기 보관, 기술 구성
- [와이어프레임](docs/WIREFRAMES.md): 주요 화면 18개, 메뉴·이동 경로, 버튼 동작, 오류·보관 상태, 좁은 화면 배치
- [개발 계획서](docs/PLAN.md): 개발 순서, 단계별 완료 기준, 요구사항별 검증 시나리오
- [로그인 실행 및 연결](docs/AUTH_SETUP.md): Supabase 설정, 인증 SQL 설치, 첫 계정 발급과 검증 방법

로그인 기능을 구현하는 첫 개발 단계입니다. 아이디·비밀번호 로그인, 세션 보호, 로그아웃과 최초 비밀번호 변경을 제공합니다. 학교·학급 배정과 수업 진도 기능은 이후에 구현합니다. 설계서는 2026-10-07에 확정한 추가 요구사항을 반영하며, PRD와 겹치는 부분은 설계서의 확정 요구사항을 우선합니다.

실행은 `npm run dev`, 접속 주소는 `http://localhost:3000`입니다. 실제 계정 로그인에는 위 연결 문서의 Supabase 인증 SQL 설치와 계정 발급이 필요합니다.
