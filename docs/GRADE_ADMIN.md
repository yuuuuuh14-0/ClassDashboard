# 학년 관리자 대시보드

구현일: 2026-10-17

학년 관리자는 최초 비밀번호 변경 후 `/dashboard`에서 배정된 학교·학기·학년의 현황을 조회한다. 학년 관리자 전용 화면은 조회 대시보드이며 해당 역할의 편집 UI는 후속 범위다. 학교 관리자·일반 선생님 화면은 [별도 구현 문서](WORKSPACES.md)를 참고한다.

## 화면

- 학년 현황: 활성 학급 수, 재적 학생 수, 공통 과목·단원 수, 담당 미배정 학급과 단원 미등록 과목.
- 진도 비교: 행은 학급, 열은 과목. 완료/전체 단원 수와 진도 막대를 함께 표시하고, 막대 끝점 위에 정수로 반올림한 진도율을 표시한다. 과목 제목은 `국어(평균: 50%)` 형식으로 학급별 진도율의 산술평균을 표시한다. 반별 원래 완료/전체 수로 계산해 마지막에 반올림하며, 단원 미등록은 계산에서 제외하고 모두 미등록이면 `평균: —`로 표시한다. 순위·종합 점수는 표시하지 않는다.
- 단원 0개인 과목은 `— · 단원 미등록`으로 표시한다. 다른 반의 셀을 선택하면 선택한 과목의 단원별 완료 상태를 조회한다. 비교표로 돌아오면 과목 필터가 유지된다.
- 학생 명단: 배정 학년의 재적 명단을 학급·이름·반 내 번호로 검색하고 12명씩 조회한다.
- 공통 교육과정: 학년 공통 과목·단원 목록을 펼쳐 조회한다.
- 모바일 비교표는 내부 가로 스크롤과 학급명 고정을 제공한다. 포커스 복귀와 30초 간격으로 서버 정보를 다시 조회한다.

## 테스트 계정과 자료

| 계정 | 이름 | 배정 |
| --- | --- | --- |
| `school.admin` | 테스트 학교 관리자 | 대시보드 테스트 초등학교의 학교 관리자 |
| `grade.admin` | 테스트 학년 관리자 | 같은 학교, 2026학년도 2학기 3학년 관리자·1반 담당 |
| `test.teacher` | 테스트 선생님 | 같은 학교·학기의 3학년 2반 일반 담임 |

새로 발급한 계정의 최초 비밀번호는 `000000`이며 처음 로그인할 때 변경해야 한다. `grade:setup-test`를 다시 실행해도 기존 계정의 비밀번호는 초기화하지 않는다. 사용자가 변경한 비밀번호를 그대로 사용한다.

3학년에는 예시 학급 3개, 예시 학생 18명, 공통 과목 6개와 단원 22개를 저장했다. 영어는 단원 미등록 상태를 확인하기 위해 비워 두었다. 모든 이름과 진도는 테스트 자료다. 4학년에도 격리 확인용 소량의 예시 자료가 있지만 3학년 관리자에게 노출하지 않는다. `test.teacher`는 사용자 요청으로 3학년 2반에 배정했고 일반 선생님 권한과 기존 비밀번호를 유지했다.

학교 관리자는 자기 학교의 전용 운영 대시보드를 사용한다. 학년 관리자 배정이 없는 학교 관리자에게 학년 관리자 대시보드를 대신 보여주지 않는다.

## 데이터와 권한

마이그레이션 `202610170003_grade_dashboard.sql`은 학기·학년·학급·담임·학년 관리자 배정, 공통 과목·단원, 진도와 명단 테이블을 추가한다. 학급·단원·진도·명단의 학교·학기·학년 관계는 복합 외래 키로 검사한다. 같은 학기의 교사 중복 배정과 학년별 활성 관리자 중복도 DB 제약으로 차단한다.

`dashboard_access()`는 현재 학교 소속과 실제 활성 배정으로 시작 화면과 선택 가능한 학년을 결정한다. `grade_admin_snapshot(grade_id)`와 `GET /api/grade-admin?grade=...`는 배정된 학년만 반환하며 진도율은 SQL에서 계산한다. 모든 조회는 사용자 세션으로 수행하고 서버 관리 키로 권한을 우회하지 않는다.

DB RLS는 활성 계정·최초 변경 완료·학교 및 소속 활성·활성 담임 및 학년 관리자 배정·진행 또는 준비 학기를 함께 확인한다. 학교 중지, 소속 해제, 담임·관리자 배정 해제, 학기 보관 후에는 이미 로그인한 세션도 읽을 수 없다. 현재 조회 단계에는 직접 테이블 쓰기를 허용하지 않으며, 후속 편집 기능에서 버전·감사를 포함한 쓰기 계약을 추가한다.

## 실행과 검증

```powershell
npm run dev
npm run grade:setup-test
npm run grade:verify-live
npm test
npm run typecheck
npm run test:e2e
npm run build
```

`grade:setup-test`는 연결된 실제 프로젝트에 위 테스트 계정·학교·배정을 만든다. 기존 계정이 다른 학교에 소속되어 있으면 자동 이동하지 않고 중단한다. 동일한 테스트 자료 ID를 재사용하고 기존 값을 덮어쓰지 않는다.

`grade:verify-live`는 무작위 이름의 별도 임시 계정과 학교 두 개로 데이터·권한을 검사하고 종료 시 정리한다. 실제 로그인·최초 변경, 학년 조회, 서버 진도율, 다른 학교·학년 차단, 직접 DB 쓰기 거부, 복합 FK, 학교·학기·소속·배정 변경의 즉시 반영을 검증한다. 영구 테스트 계정의 비밀번호나 배정은 바꾸지 않는다.

2026-10-17 단위 테스트 5개, 브라우저 테스트 11개, 타입 검사·배포 빌드와 실연결 검증을 통과했다. 데스크톱·모바일 학년 화면과 로그인 화면의 문의 이메일도 확인했다.
